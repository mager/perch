Try it on your Mac first

With Node.js 22 installed, clone the repository and start the local sample dashboard.

git clone https://github.com/mager/perch.git
cd perch
npm ci
npm run demo

Open http://localhost:8787/app. Sample mode needs no accounts and does not monitor your actual Mac.

Still finding its wings. Perch is in development. Hosted sign-in, Redis, and the Mac agent still need end-to-end verification. Free provider tiers are the target, not a billing guarantee. The native menu bar app is in developer preview; Apple signing and notarization are still pending.
